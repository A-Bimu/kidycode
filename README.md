# KidyCode

Project-led coding education for young makers and adult beginners.

The public experience includes a marketing landing page, separate curriculum
paths for ages 10 to 18 and adult beginners, animated origami guides, and an
interactive logic mission.

The first learning product is now included at `learn/`. Code Explorers serves
ages 10 to 12 with 13 stages, 114 activities, 12 boss projects, a capstone,
mastery stars, evidence badges, a private on-device portfolio, version snapshots
and a grown-up progress view.

Run both checks before publishing:

```sh
node scripts/validate-curriculum.mjs
node scripts/validate-static.mjs
node scripts/test-learning-flow.mjs
```

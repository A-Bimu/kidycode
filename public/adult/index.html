This course does not pretend to make a beginner job-ready overnight. It teaches the web skills and problem-solving habits needed to finish a small site, discuss the code and choose a sensible next step.

THE COURSE, IN EIGHT MODULES

From readable pages to working interactions.

Each module contains four lessons, one project checkpoint and one short review. Notes, practice and checks live on separate screens so the work stays focused.

01

Semantic HTML

Build clear page sections with headings, links, images and meaningful landmarks.

02

Useful forms

Add labels, input types, groups, instructions and browser validation.

03

A CSS system

Control type, colour, spacing, reusable values, focus states and hierarchy.

04

Responsive layout

Design mobile first, then use flexible grids and media queries for larger screens.

05

JavaScript logic

Work with values, conditions, functions, parameters and return values.

06

Data and rendering

Organise records, filter and sort them, then turn the result into visible content.

07

The browser and storage

Respond to user actions, validate text and keep useful information between visits.

08

Test and release

Check keyboard use, handle errors, protect privacy and document what the release can do.

THIS COURSE FITS IF

You want understanding, not copied code.

  • You are completely new or starting again after a long gap.
  • You want to make a website for a practical reason.
  • You learn best when a clear example is followed by immediate practice.
  • You can protect a few focused study sessions each week.
  • You are willing to inspect errors and explain your choices.

What comes next: deeper front-end study, a larger portfolio project, supervised client work or another technical path with a much stronger foundation.

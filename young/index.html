YOU DO NOT NEED TO KNOW CODE

Ask for a tour, not a score.

At the end of a study session, three questions reveal more than a percentage:

  1. What did you add to your website today?
  2. Which line did not work the first time?
  3. What would you improve next?

The learner should be able to open the result, point to their code and answer in their own words.

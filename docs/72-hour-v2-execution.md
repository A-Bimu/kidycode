# KidyCode V2 — 72-hour build and dry-run release

## Outcome
Move from a single guided project in each pathway to evidence that learners can transfer skills to a different problem. Dry-runs precede human pilots. Human evidence, institutional approval, and co-branded certificates remain independent gates.

## Day 1 — contracts
- Signed-in LMS accounts, learner linking, persistent enrolments.
- Four age-specific transfer-project banks and four scaffolding levels.
- Organisation, cohort, institution roles and academic-review data boundaries.
- Independent-start, planning, working-behaviour and changed-requirement evidence.
- **Gate:** schema and role checks pass; every pathway has a transfer-project contract.

## Day 2 — product experiences
- Learning dashboard, course catalogue, Notes Library, separate Practice Lab.
- Separate age-adapted UI/UX Design course.
- Build Outside KidyCode: files, VS Code, DevTools, Git, GitHub, publishing.
- Institution pilot workspace, curriculum map, Skills Evidence Record, approval-gated certificate language.
- **Gate:** routes build and work on phones, tablets and laptops; real/demo/pending data labelled.

## Day 3 — dry runs
- Simulate all four pathways: failed first attempt → corrected retry, changed requirement, independent start.
- Exercise persistence, transfer replay refusal, role isolation, certificate eligibility.
- Run typecheck, lint, curriculum and database contracts, production build, E2E and browser smoke suites.
- Record logs and exact verified commit, submit a reviewable branch/PR only after gates pass.
- **Gate:** no severity-one defects, passing local checks and reviewed release candidate; no automatic public publish.

## Boundaries
- Work only in A-Bimu/kidycode; never ALIA, Eureka or KOVU.
- No production database changes, public publishing, accreditation claims, or exposure of child data.
- 3 children + 1 adult pilot only after guardian consent and controlled beta access.
- $20 project budget is a requested policy, not a programmatic spending cap; do not start an unbounded paid loop.

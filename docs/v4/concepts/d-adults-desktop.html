Objective

Make a stylesheet stay readable as it grows

Six months from now you will open this file to change one colour. If the same colour is written in twelve places, that is twelve edits and one inevitable mistake.

The fix is a small habit: name your values once, at the top of the file, and use the names everywhere else. This is what design tokens are — a short list of decisions, written down.

Why this matters at workHanding a project to a colleague, or coming back to it yourself, is the normal case. Consistency is what makes that cheap.
/* name it once */
:root {
  --brand: #1b4fbf;
  --ink: #0e1726;
}

/* use the name */
.button { background: var(--brand); }
  1. 1Read what happens when the same colour is copied nine times.
  2. 2Change one named value and watch every button change with it.
  3. 3Do the same in your own project — three names is enough to start.

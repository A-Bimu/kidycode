A page that works things out for itself

You already know how to put a number on a page by typing it. That breaks the moment a visitor orders something different — the page would be lying.

JavaScript lets the page hold a value in a variable and work with it: read two ticket prices, add them, and write the result into the page. Change the input, and the total changes with it.

You will meet three words today — variable, function, return — but only after you have made the total update once.

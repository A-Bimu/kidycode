Updating one record without losing the others

An array of tasks is the source of truth. To change one task you do not edit it in place — you build a new array where every other entry is carried across untouched, and the matching one is replaced.

This one is genuinely fiddly. Most people get it wrong the first time by mutating the array in place. That is why there are three checks and a failing test to read, not one.

Removing is the same shape with one entry dropped. Once you can do both, "CRUD" stops being four letters and becomes two functions you have written.

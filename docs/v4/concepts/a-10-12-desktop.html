Module 1 · Lesson 4

Build a useful list

There is only one thing to learn here: a list is a stack of lines. That is the whole idea. The rest is typing.

Try it: add a fourth lineType in the box on the right — the page changes as you type
1

A list is a stack

Think of a shopping list: lines, one under another. On a web page a list is exactly the same — except the browser writes it out for you.

2

You already built one this morning

Your page has a title, a paragraph and a link. A list is the same pattern, stacked.

3

Now the words for it

Unlocks in Practice: an unordered list is a list with dots. Each line is a list item. That is all the jargon, and you will have used it before you read it.
